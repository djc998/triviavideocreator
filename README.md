# Video Generator

A flexible video generator for creating quiz-style videos in both standard and TikTok formats.

## Features

- **Multiple Formats**
  - Standard (1280x720)
  - TikTok (1080x1920)
  - Customizable dimensions

- **Text Handling**
  - Custom font support
  - Dynamic text sizing
  - Automatic text wrapping
  - Shadow and outline effects
  - Position control (center, left, right, top, bottom, or custom coordinates)
  - Fade effects

- **Timer**
  - Circular or square shape
  - Customizable position and size
  - Optional sound effects
  - Color customization

- **Video Generation**
  - Multiple question support
  - Background image or color
  - Audio support with looping
  - Preview mode for testing
  - Multi-part video generation (TikTok mode)

- **Overlays**
  - Custom text overlays
  - Timing control
  - Position and fade effects
  - Font and style customization
